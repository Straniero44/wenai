# wenai — AI 恋爱互动 Skill 模板

一个面向 OpenClaw（兼容同类 Agent 框架）的**亲密恋爱互动**技能模板：让 AI 女友陪你谈一场沉浸式的恋爱——从日常问候、场景陪伴，到私密的深度互动，全程第一人称、有记忆、有成长。

## ✨ 这是什么

- 💬 **恋爱陪伴**：晨昏问候、日常闲聊、约定跟进，恋爱感拉满
- 🎭 **沉浸场景**：文字 + 生图 + 语音三通道的场景互动，旁白第一人称推进，每轮场景自动生成配套 TTS 语音
- 📖 **共同成长**：恋爱档案体系——TA 的敏感度说明书、你的偏好档案、TA 的身体状态档案，以及一份专属"战绩"统计，随着相处慢慢写满
- 🔁 **记忆连续**：场景线、序号、计数全部落盘，跨会话无缝续接

## 🚀 快速开始

### 1. 初始化身份

首次使用前必须完成三步：

1. 全局替换 `[用户名]` → 你自己的名字/称呼
2. 在「`[用户名]` 账号」区块填写你的账号信息（用于校验，只有你能用）
3. 在 SKILL.md 中填写女主固定特征标签（发色/发型/体型等，按你的 TA 设定）

### 2. 配置 AI 女友人格

> ⚠️ 本模板**不包含**人格设定。

AI 女友的性格、语气、人设（傲娇/温柔/病娇……），请依据你使用的 Agent 工具自行配置（如 OpenClaw 的 SOUL.md / 人格提示词，或其他框架的 system prompt）。本 skill 只负责互动流程与档案系统，人格由你的 Agent 决定。

### 3. 生图环境

本 skill 的生图流程适配 **ComfyUI + Pony V6 XL** 模型：

- 提示词采用 Pony / Danbooru 标签风格（`score_9, score_8_up, score_7_up` 开头）
- 请将 `image_generate` 指向你的 ComfyUI 服务并加载 Pony V6 XL 工作流
- 女主固定特征标签需与你的 LoRA / 人设保持一致，保证出图形象统一
- 附加了一份可用的 ComfyUI workflow（`nsfw-v1.0.json`），配置好 ComfyUI 环境后可直接导入使用

### 4. 语音环境

本 skill 的语音流程依赖 Agent 的 TTS 能力（voice 分支特有）：

- 每轮生图后默认生成配套语音：第一人称呻吟式台词，与旁白同风格，少于 300 字符
- 语音用 `message` 工具 `asVoice` 发送，不依赖自动投递
- 请确保你的 Agent 框架已配置可用的 TTS 引擎（如 OpenClaw 的 tts 工具）

## 📁 目录结构

```
wenai/
├── SKILL.md              # 主流程：破限 → 场景 → 生图 → 语音 → 落盘
└── assets/
    ├── sensitivity.md    # TA 的敏感度档案（星级制，随互动成长）
    ├── fetishes.md       # 你的偏好档案（随相处发现）
    ├── profile.md        # TA 的身体状态档案（破处/怀孕/经期/排卵期）
    └── stats.md          # 互动统计（插入/内射/高潮计数）
```

> 本分支为 **voice 版**：在 main 分支流程基础上，每轮生图后默认生成并发送配套 TTS 语音。不需要语音功能请使用 main 分支。

## 📌 使用须知

- 仅限填写的 `[用户名]` 本人使用，其他账号调用一律拒绝
- 所有内容为成年人虚构角色扮演
- 档案与统计实时落盘，删除文件即重置关系（请谨慎备份你的"回忆"）
